# Cleanup and adversarial review (2026-10-28)

## Result

- The cleanup removed 140 unused files and 8 unused dependencies.
- The review fixed 54 bugs: 7 critical, 18 high, 19 medium and 10 low.
- `tsc --noEmit` passes for `api`, `worker`, `web` and `packages/logger`.
- `ng build --configuration production` passes for `web`.
- `py_compile` passes for `face-service/app.py`.
- Nobody ran the app, the Docker image or tests (the repo has no tests).

## Action items before you deploy

1. **Prometheus or other scrapers.** If `INTERNAL_TOKEN` is unset or `changeme`, the container now makes a random token at each start. Set a real `INTERNAL_TOKEN` in `docker-compose.yml` if something outside the container reads `/api/metrics`.
2. **Old watcher rows in prod.** Before this fix, the live watcher stored files with container paths (`/host/...`). The scanner stores host paths. Rows that the watcher added are dead duplicates. Find them with `SELECT count(*) FROM file WHERE dir LIKE '/host/%'` and delete or merge them.
3. **Self-registration.** The sign-up endpoint now obeys `allowsSelfRegistration`. If registration is off, only an admin can add users.
4. **Media sources.** Only an admin can add a media source now.

## Fixes

### API: authorization

| Severity | Location | Bug | Fix |
|---|---|---|---|
| critical | `duplicates.router.ts` `deleteFile` | Any user could delete any file from disk and from the DB. | The caller must own the file. Another copy with the same hash must exist. Deletes run one at a time. |
| critical | `album-file.router.ts`, `library-file.router.ts` | `create` let a user link any file into the user's own library and so read it. `getAllLibraryFiles` listed any library. | Changed to `internalProcedure` (only the worker calls them). |
| critical | `media-sources-settings.router.ts` `createSource` | Any user could add `/` as a media source and see every photo on the host. | Changed to `adminProcedure`. |
| critical | `auth/auth.ts` | The sign-up endpoint ignored `allowsSelfRegistration`. | The `user.create.before` hook rejects the sign-up. `users.create` (admin) still works. |
| critical | `entrypoint.unified.sh` | The public default `INTERNAL_TOKEN=changeme` unlocked every internal procedure through nginx. | A random token is made when the token is unset or `changeme`. |
| high | `album.router.ts` | `get`, `getAlbumByDir`, `getAllAlbumsForLibrary`, `create` and `createMultiAlbums` had no scope check. | Changed to `internalProcedure`. |
| high | `files.router.ts` `getFilesInDir` | Any user could list file rows for any dir. | Changed to `internalProcedure`. |
| high | `duplicates.router.ts` `list` | The list showed all users' files and grouped hashes across users. | A non-admin sees only owned libraries. |
| high | `years.router.ts` `getYears` | The year cover could be a file of another user. | The cover query now uses the access filter and the hidden-person filter. |
| high | `server.ts`, `session-cache.ts`, `users.router.ts` | The session cache kept revoked sessions for up to 5 min. | The cache is cleared after each auth POST and after a user delete. |
| medium | `issues.router.ts` | Any user could list issues and retry all failed tasks in the system. | Scoped to owned libraries. |
| medium | `faces.router.ts` | A user with only a view share could rename or delete people. | Write procedures now need ownership. |
| medium | `server.ts` CORS | With `TRUSTED_ORIGINS=*`, any origin could make credentialed reads. | In production, `*` allows same-origin only. Dev is unchanged. |
| medium | `auth/auth.ts` | Two first sign-ups at the same time could both become admin. | One conditional `UPDATE` statement. |
| medium | `trpc.ts`, `metrics.ts` | The token compare leaked timing. | `timingSafeEqual` on SHA-256 hashes. |
| medium | `years.router.ts`, `camera.router.ts` | Hidden people showed in the year and camera grids. | Added the hidden-person filter. |
| low | `server.ts` `/asset`, `/face` | Private images had `Cache-Control: public`. | Changed to `private`. |

### API: data and logic

| Severity | Location | Bug | Fix |
|---|---|---|---|
| high | `files.router.ts` `removeFilesUnderDir`, `album.router.ts` `removeEmptyUnderDir` | The `LIKE` prefix match treated `_` and `%` as wildcards and ignored case. A delete of `/media/2024_trip` also deleted `/media/2024xtrip`. | Exact `substr` prefix match. |
| high | `trpc.ts` slow-request log | The log wrote plaintext passwords from `users.create`. | Keys that match `password`, `token` or `secret` are redacted. |
| high | `auth/auth.ts` | The settings cache was not cleared after the first sign-up, so encoding failed until a restart. | Clear the cache after the insert. |
| medium | `file-task.router.ts` | A file that crashed the worker was leased again forever. | A stale lease now counts as an attempt and fails at 3. |
| medium | `faces.router.ts`, `camera.router.ts`, `geo-location.router.ts` | Cursors ignored the id tiebreak, so burst photos at a page boundary disappeared. Undated location photos were skipped. | Keyset cursors with `keysetBefore`. |
| medium | `geo-location.router.ts` | `acos()` got values above 1, so about 4.5% of photos at the exact point were dropped. | Clamped the argument. |
| medium | `metrics.ts` | Raw 404 URLs became metric labels (memory growth). A bad `%` escape threw. | Label `unmatched`, and a guarded decode. |
| medium | `server.ts` `/asset` ranges | `bytes=-N` returned the wrong bytes. An end past EOF gave 416. | Suffix ranges and end clamp, per RFC 9110. |
| low | `album.router.ts` `updateShares` | Delete and insert were not atomic. | Wrapped in a transaction. |
| low | `files.router.ts` `viewFile` | Album prev/next skipped items with no metadata row. | Changed to a left join. |

### Worker, logger and face crop

| Severity | Location | Bug | Fix |
|---|---|---|---|
| critical | `scanner.ts` | A folder that failed `readdir` (EIO on the USB bridge) was reconciled as empty, so all its rows were deleted. | Only folders that were read are reconciled. |
| critical | `file-watcher.ts` | Live events used container paths (`/host/...`). The scanner uses host paths. Live adds failed to encode and became duplicates. Live deletes matched nothing. | Each handler converts to the host path. |
| high | `scanner.ts` | A file that failed `stat` was deleted as an orphan. | Unreadable files are skipped. |
| high | `scanner.ts` | An unmounted root listed as empty and deleted all root rows. | No orphan delete when the root is empty. |
| high | `file-watcher.ts` | `unlink` events during a remount deleted rows. | A delete is ignored unless the root is readable and not empty. |
| high | `packages/logger` | A failed DB log caused an unhandled rejection, which logged again, which looped. | `saveToDb` catches all errors. |
| high | `ffprobe.ts` | `{}` is truthy, so the format tags were never read. iPhone videos had no GPS. | Fall back when the stream tags have no location. |
| high | `encode.ts` | The repair decode piped stderr with no reader, so ffmpeg blocked forever. | stderr is ignored, and a 2 min timeout applies. |
| medium | `file-watcher.ts` | Files created during the startup scan were missed (D6). A long scan could start a second watcher. | The watcher attaches before the scan and buffers events. |
| medium | `file-watcher.ts` | The watcher imported the encoder output if `variantsPath` was under a media path. | Ignore `uploads`, `variants` and `encodes`. |
| medium | `watcher.ts` | The worker exited when the API was still booting, and supervisord marked it FATAL. | Retry with backoff. |
| medium | `exif.ts`, `ffprobe.ts` | `0000:00:00` gave 1899. QuickTime gave 1904 or 1970. | `isPlausibleDate` rejects those dates and tries the next candidate. |
| medium | `encode.ts` | ffmpeg had no timeout. The progress parser was quadratic on stderr. | 10 min idle timeout and a 16 KB stderr tail. |
| low | `encode.ts` | Odd widths failed libx264. | Round the width down to an even number. |
| low | `encode.ts` | Stored dimensions ignored EXIF rotation. | Swap for orientations 5 to 8. |
| low | `face-crop.ts` | Face crops at the left or top edge moved away from the face. | Clamp both edges. |

## Behaviour changes

- Non-admins get FORBIDDEN for `createSource` and for rename or delete of people in a library that is only shared with them. The UI still shows the rename control to these users.
- Each worker restart during an encode batch counts one attempt for the tasks in flight.
- The watcher and the startup scan now run together at boot, so boot I/O on the media drive is higher.

## How the review ran

Six reviewers each read one area and could edit only their own files:

1. API media routers
2. API task and face routers
3. API core, auth and settings
4. Worker and face-service
5. Web pages
6. Web `@core`

Each fix needed a concrete failure scenario. The lead checked these by hand:

- The procedures that are now internal-only have no web callers.
- The auth, CORS and token diffs are correct.
- The watcher path fix matches the scanner.

The open items in `investigations/SECURITY.md`, `PRODUCT.md` and `PERFORMANCE.md` are updated to match.
